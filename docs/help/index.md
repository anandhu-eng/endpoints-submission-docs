# Help

| Page | Use when |
|---|---|
| [Troubleshooting](troubleshooting.md) | Something failed and you have an error message |
| [FAQ](faq.md) | You have a process or policy question that is not an error |
| [Open questions and WIP rules](open-questions.md) | You need to know what could still change under you |
| [Getting support](support.md) | You need a human |

!!! tip "Start with the error text"
